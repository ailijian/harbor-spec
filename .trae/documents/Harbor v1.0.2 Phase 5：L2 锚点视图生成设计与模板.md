# 目标
- 实现 `L2Generator`：聚合 L3（索引）+ DDT（绑定验证）为稳定 Markdown 视图。
- 集成 CLI `harbor gen l2 --module <path> [--write]`，并通过 `l2_meta.json` 控制抖动与提示。

## 输入与聚合
- 输入：`module_path`（例如 `harbor/adapters/python`）
- 数据源：
  - 索引缓存：`.harbor/cache/l3_index.json`（函数 `id/strictness/contract_hash/docstring_raw_hash/scope` 等）
  - DDT 校验：`DDTScanner.scan_tests()` + `DDTValidator.validate()`（得到 Valid / Violations）
- 选择与分组：
  - 以 `file_path` 前缀匹配 `module_path` 下的函数
  - 分组为 `Public` 与 `Internal`（依据 `scope` 字段）
- 稳定性：
  - 所有函数按 `Function Name` 字母序排序（点分 `qualified_name` 的最后段）
  - 生成内容的关键摘要（scope/strictness/ddt 状态/summary）组成一个稳定哈希，写入 `.harbor/l2_meta.json`；若哈希未变 → 输出 "No changes needed"

## Markdown 模板（示例）
```markdown
<!-- AUTO-GENERATED BY HARBOR (v1.0.2). DO NOT EDIT MANUALLY. -->
# Module: harbor/adapters/python

Generated At: 2025-12-16T10:00:00Z
Source: .harbor/cache/l3_index.json

## Public API
| Function | Summary | Strictness | DDT Status |
|---|---|---|---|
| harbor.adapters.python.parser.PythonAdapter.parse_file | 解析并提取指定 Python 文件中的函数/方法契约元数据。 | strict | ❌ Missing |

## Internal Details (optional)
<details>
<summary>Internal functions</summary>

| Function | Summary | Strictness | DDT Status |
|---|---|---|---|
| harbor.adapters.python.parser.PythonAdapter._extract_functions | 提取顶层函数与类方法的契约元数据。 | standard | ❌ Missing |
| harbor.adapters.python.parser.PythonAdapter._contract_area | 提取契约区文本（Args/Returns/Raises + @harbor.* tags）。 | standard | ❌ Missing |

</details>

## Dependency (MVP)
- (TBD) 未来基于 import 简要分析模块依赖。
```
- Summary 抽取策略：
  - 优先取 Docstring 第一段（第一行非空）
  - 若不存在 Docstring → 以 `—` 占位
- DDT Status 映射：
  - ✅ `Valid`
  - ⚠️ `Violations`（包含 `version_mismatch/strict_forbid_latest/missing_binding_info`）
  - ❌ 未绑定（未在扫描中出现）

## 类接口设计（L3）
- 位置：`harbor/core/l2.py`
- `class L2Generator`
  - `generate(module_path: str) -> str`
    - public/strict Docstring：描述聚合与稳定化策略
    - 返回：Markdown 文本
  - `write(module_path: str, md: str) -> None`
    - 写入 `modules/**/README.md` 或指定路径下的 `README.md`（本项目采用模块路径目录下）
  - `compute_meta_hash(entries) -> str`
    - 根据排序后的条目生成稳定哈希；与 `.harbor/l2_meta.json` 比较

## CLI 集成
- `harbor gen l2 --module <path> [--write]`
  - 行为：生成 Markdown；若 `--write` → 写入 `<module_path>/README.md`
  - 输出：生成时间、函数计数、DDT 有效数、Violations 数；若无变化打印 "No changes needed"（除非 `--force`）

## 测试与 Dogfooding
- 运行：`harbor gen l2 --module harbor/adapters/python --write`
  - 目标：生成 `harbor/adapters/python/README.md`，`parse_file` 的 DDT 状态为 ❌ Missing（或后续我们也可绑定测试以变更状态）

## 风险与缓解
- Summary 抽取的多风格兼容：MVP 采用第一行策略；后续可解析 Google 风格完整摘要
- DDT 扫描有限（常量参数）：后续可以加入运行时元数据读取增强覆盖率
- Meta 控制：哈希纳入必要字段，避免因无关空白/顺序导致抖动
