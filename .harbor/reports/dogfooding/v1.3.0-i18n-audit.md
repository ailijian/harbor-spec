## Root Cause Analysis
用户配置中文后 `harbor checkpoint --ci` 仍输出英文的根因：
- `checkpoint --ci` 文本输出路径不走 `t()`，而是直接走 `harbor/core/ci.py` 的 `format_checkpoint_ci_result()`。
- `format_checkpoint_ci_result()` 与 `format_ci_result()` 内部消息（标题、分组、next steps）为硬编码英文。
- 同时，CI 结果中 `reason/suggested_action` 也多由 `build_*_ci_result()` 的英文常量构造，进一步固化英文输出。
- 因此即使 `get_lang()` 正确返回 `zh`，CI 文本链路仍不会受影响。

## Recommended Fix Plan
只提出建议，不实施：
1. 将 `harbor/core/ci.py` 中所有文本（formatter + reason/suggested_action）迁移为 i18n key，统一调用 `t()`。
2. 将 `harbor/core/init_wizard.py`、`harbor/core/doctor.py`、`harbor/core/stale.py` 的直写文本抽离到 i18n 词条，消除 mixed-language。
3. 为 CLI 错误路径（如 `parser.error`）补齐 i18n，确保 zh/en 模式下错误提示同语言输出。
