## B. Release Note Summary（可直接用于发布说明）

## Harbor-spec v1.3.0

### Highlights

- Canonical Workspace 正式收敛到 `.harbor/`，上下文治理边界清晰（canonical / export / legacy / cache / state）。
- AI 工作流闭环稳定：`checkpoint -> finish --sync-context -> stale -> doctor`。
- CI Gate 行为可解释：`checkpoint --ci`、`stale --ci`、`doctor --ci` 可作为机器门禁。
- Contract Impact Classifier 可区分低风险改动与 CLI/JSON/write-target 等高风险信号。
- Workspace 诊断与迁移预览支持只读模式（`inspect` / `migrate --dry-run`），默认 no-write。

### Validation Snapshot

- Tests: `pytest` 全量通过（`335 passed`）。
- CI Gates: `checkpoint --ci` / `stale --ci` / `doctor --ci` 全通过。
- Local Workflow: `checkpoint` / `stale` / `doctor` 全通过且 clean。
- Workspace Safety: inspect/migrate dry-run JSON 为单对象，且 `writes_files=false`。

### Dogfooding Outcome

- S1-S7 已补跑，未发现 release blocker。
- 关键行为已验证：
  - 高风险改动（CLI/JSON/write-target）能被识别并阻断；
  - generated views stale 可被 `finish --sync-context` 收敛；
  - legacy/export advisory 不误伤 canonical gate。

### Known Constraints（v1.3.0 边界）

- `checkpoint --ci` 对语义漂移采用保守策略；当存在可能语义漂移时会阻断，需人工裁决。
- `workspace migrate --dry-run` 为 advisory 只读，不执行真实写入迁移。

### Release Recommendation

- Recommendation: **Freeze and tag v1.3.0**.
- 发布执行建议（由人工执行）：
  1. 确认本地与远端分支状态。
  2. 创建并校验 tag（如 `v1.3.0`）。
  3. 推送 tag 与 release note。
