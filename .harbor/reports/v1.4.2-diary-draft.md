## Why

`v1.4.1` 先完成了 Log Draft + Controlled Write workflow。  
恢复 TypeScript 主线时，团队决定先补齐 generalized persistence 与 accepted baseline artifact compatibility，再继续 richer TypeScript contract source strengthening，避免在未稳定入 baseline / snapshot / JSON pipeline 的前提下提前扩张 TypeScript治理范围。

## What Changed

- TypeScript `ContractSubject` 进入 generalized persistence / index integration。
- accepted baseline artifact 继续保持 `checkpoint --ci` baseline truth。
- exported `interface` / `type` 作为 advisory-first data contract target 被识别。
- `z.object(...)` / `z.enum(...)` 作为 shallow contract source 被识别。
- `export default function` / `export default class` 作为 public surface evidence 被识别。
- TypeScript `contract_hash` 改为 normalized contract source bundle hash。
- checkpoint / `harbor next` / JSON 输出增加 additive TypeScript metadata。
- generated context closure 明确采用 `finish --sync-context -> stale --ci -> doctor --ci`。

- 不写正式 `.harbor/diary/**`，只保留 reviewable draft。
